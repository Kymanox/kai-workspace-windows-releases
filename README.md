# Kai Workspace Windows releases

Public signed Windows installers, updater metadata, and release assets for Kai Workspace.

For a first installation, download the `Kai-Workspace-Setup-<version>.exe` installer from the latest stable release. Existing installations use `latest.yml` and the associated installer and blockmap files for updates.

Published tags and asset filenames are compatibility interfaces. Preserve existing releases and their signed assets when changing repository organization or naming.
